# Yoyo Track

Aplicación en **React + TypeScript** creada con **Vite** para gestionar inventario y deudas de clientes de snacks.  
Permite registrar productos, añadir consumos, abonos y calcular saldos pendientes en una interfaz sencilla.

## 🚀 Tecnologías
- React 18
- TypeScript
- Vite
- CSS Modules (o estilos básicos)

## 📦 Instalación
Clona el repositorio y entra en la carpeta:

```bash
git clone https://github.com/it02Inartec/yoyo-track.git
cd yoyo-track

Instala las dependencias:
npm install

▶️ Uso
Ejecuta el proyecto en modo desarrollo:
npm run dev

Abre en tu navegador:
http://localhost:5173
